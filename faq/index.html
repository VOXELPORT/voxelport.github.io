VoxelPort frequently asked questions

The things people ask before they install VoxelPort, answered in plain words.

Is VoxelPort moving to a new app?

Yes. VoxelPort was rebuilt on newer technology: the new app (2.0 beta, Windows) is about 3 MB instead of over 100 MB and does the same things, and new features only come to it. In your current app (1.18.0) press “Update to the new VoxelPort”: it downloads and checks the new app, installs it, brings your servers, backups, VoxelPort ID, address and settings across, then removes the old app. Your server folders and worlds are never touched, and if anything goes wrong the old app and your data stay as they are. You sign in with Discord once in the new app. Microsoft Store users: the Store cannot install another app, so download the new one from the download page, open it and use its banner to bring your data over, then remove the Store version.

Windows 11 says Smart App Control blocked the installer. What do I do?

The new app is not code-signed yet, so with Smart App Control on, Windows blocks its installer and there is no “Run anyway” button. To install it, switch Smart App Control off: Settings › Privacy & security › Windows Security › App & browser control › Smart App Control settings › Off. Windows cannot turn it back on later without reinstalling Windows, so if you would rather not, keep using your current VoxelPort, which keeps working.

How do I host a Minecraft server without port forwarding?

Install VoxelPort, create or import a server, press Start and then Make public. VoxelPort connects your server out to its relay, which gives you a public address. Players connect to the relay, so nothing has to be opened on your router.

Is VoxelPort really free?

Yes. The app and the relay are free and open source under the MIT license. There are no ads or player limits, and players need no account. Hosts sign in with Discord and join our Discord server.

Do my friends need to install anything?

No. Java players use normal Minecraft: Java Edition and paste your address into Multiplayer → Add Server. Bedrock players use their normal game too.

Is there a relay in Europe?

Yes. VoxelPort has a relay in India and one in Europe (from app version 1.11). The Region setting is on Auto by default and picks the faster one for you; you can also choose a region by hand. Custom addresses are only on the India relay for now.

Does it work behind DS-Lite or CGNAT?

Yes. DS-Lite and CGNAT block incoming IPv4 connections, which breaks port forwarding. VoxelPort needs no incoming connection: your PC connects out to the relay, so it works on those connections too.

Can Bedrock players on phones and consoles join?

Yes. Turn on “Let Bedrock players join” in your server’s settings and VoxelPort installs Geyser and Floodgate for you (Paper and Fabric servers). Bedrock players join on the same address and port.

Can I get my own server address?

Yes, as a supporter. Supporters can claim a custom name so players join with yourname.voxelport.in, with no port number needed in Java Edition. Everyone gets a free address like play.voxelport.in:26137.

Does it work with mods, plugins and modpacks?

Yes. VoxelPort can set up Vanilla, Paper and Fabric servers, import any server folder you already have, or put any server that is already running online.

Does VoxelPort hide my home IP address?

Yes. Players only ever connect to the relay, never to your PC, so your home IP address isn’t exposed to them.

Where can I get help or ask a question?

In the VoxelPort Discord (https://discord.gg/JAUfmey2fP): ask in #help, suggest features, and hear about every release first. Friends who only play need no Discord at all; hosts sign in with Discord in the app. There are also step-by-step guides on this site.

How do I keep my address when I get a new PC or phone?

Back it up first. In the app, open Address backup and choose a passphrase of at least 12 characters. The app locks your address key with it on your device and saves only the locked copy to your Discord account, so VoxelPort cannot read it and cannot recover a forgotten passphrase. On the new PC or phone, sign in with Discord, open Address backup and restore it. The PC app and the Android app use the same backup, so you can move between them. It needs the latest version of the app.

How is VoxelPort different from playit.gg or ngrok?

VoxelPort is made only for Minecraft: it sets up the server and Java for you, adds Bedrock crossplay and a free public address (custom names for supporters), asks hosts to sign in with Discord and join our server instead of making a password account, and is fully open source.
