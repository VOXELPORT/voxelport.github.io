playit.gg, ngrok and Hamachi Alternative for Minecraft

A free playit.gg, ngrok and Hamachi alternative made only for Minecraft: no port forwarding, no signup for friends, friends join with plain Minecraft. What is different.

What VoxelPort does differently

  • It runs the server too. You don’t install Java, download a server jar and then set up a tunnel: VoxelPort does all of it, with Vanilla, Paper, Fabric and modpack templates.
  • A permanent address. Your port belongs to your install (and a supporter’s custom yourname.voxelport.in too), so friends save the server once.
  • Java + Bedrock. One switch adds Geyser and Floodgate, and Bedrock traffic (UDP) goes through the same relay.
  • No card, open source. The app and the relay are MIT-licensed; hosts join our Discord server once.

Questions

What is the best alternative to Hamachi for Minecraft?

A tunnel or relay, so your friends don’t install anything. With VoxelPort your friends join with plain Minecraft using an address, and there is no member limit.

Does ngrok work for Minecraft for free?

It can, but ngrok’s free plan asks you to add a credit or debit card before TCP endpoints work, and the address changes when you restart. VoxelPort needs no card and keeps your address.

Is VoxelPort like playit.gg?

Both put a home server online without port forwarding. VoxelPort is also a server manager: it installs and runs the server, Java and Bedrock support for you, and supporters can get a custom address (yourname.voxelport.in).

Do my friends need to install anything?

Not with VoxelPort, playit.gg or ngrok: they join with normal Minecraft. With Hamachi everyone installs Hamachi, and with mods like e4mc or Essential the host (and with Essential, often friends) needs the mod.
