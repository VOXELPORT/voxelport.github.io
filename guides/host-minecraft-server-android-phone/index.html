Host a Minecraft Server on Your Android Phone (Free)

Run a real Minecraft: Java server on your Android phone with the free VoxelPort app. Friends join from anywhere, no port forwarding, Java + Bedrock.

Your Android phone is a small Linux computer with several gigabytes of RAM — plenty to host a Minecraft server for a few friends. VoxelPort for Android runs a real Paper (Java Edition) server right on the phone and puts it online through the VoxelPort relay, so friends join from anywhere without port forwarding.

A phone is not a PC. Android can close apps in the background, and mobile data or a phone with little RAM is the hardest way to host. Use Wi‑Fi, keep the app open, and use the PC app for a server that has to stay up. It is shared as a direct APK (not on the Play Store yet) and needs an arm64 phone on Android 8 or newer.

Install the app

  1. On your phone, download the VoxelPort APK (about 55 MB).
  2. Open the downloaded VoxelPort.apk. Android will ask to allow installing from this source — turn it on for your browser, then tap Install.
  3. If Play Protect warns about an unknown app, or says it “may be harmful” because it isn’t from the Play Store, tap More details → Install anyway. It’s the same open-source project as the desktop app.

Start a server

  1. Open VoxelPort. It first asks you to Continue with Discord: sign in, and join the VoxelPort Discord server if you aren’t in it yet (the app shows the invite). Then allow the notification it asks for.
  2. Under Server: tick I agree to the Minecraft EULA, leave Bedrock players on if you want phone/console friends to join, and pick the RAM to give it (2 GB is a safe start).
  3. Tap Install — it downloads the server (about 135 MB; Java is already inside the app), so use Wi‑Fi. On mobile data the app asks before it starts. Then tap Start. The first start generates the world and can take a few minutes; watch the console for Done!.

Let friends join

  1. Tap Make Public. Allow it to ignore battery optimisation, so Android doesn’t kill the server in the background.
  2. Copy the address it shows (like play.voxelport.in:26137); supporters can also claim a custom yourname.voxelport.in.
  3. Share it. Friends open Multiplayer → Add Server and paste it. Bedrock (phone/console) players use the same address.

Keep your address on a new phone or PC

Your public address belongs to a secret key stored on this phone. To keep it if you reinstall or switch devices, open the Address backup panel, tap Back up my address and choose a passphrase of at least 12 characters. The app saves a locked copy to your Discord account; VoxelPort can’t read it and can’t recover a forgotten passphrase. On the new phone (or in the PC app, which uses the same backup), sign in with Discord and tap Restore my address.

Updating from an older build? Android can’t update the earliest builds in place, because the app’s signing key changed. Open Back up or restore your address first and copy your code, then uninstall, install the new APK and restore the code. Uninstalling deletes the server files stored inside the app, so copy out anything you want to keep. Updates from now on install normally.

To remove a server you no longer want, stop it and tap Delete server under Setup. Your backups, address and Discord sign-in are kept.

Add plugins and mods in one tap

Tap Add plugins to browse Modrinth from inside the app: search, tap Install, and the plugin (plus anything it needs) goes straight into your server. Restart to load it. Want mods instead? Under Version → Change, switch the server software from Paper (plugins) to Fabric (mods) and the same button browses Fabric mods. Settings changes the game mode, difficulty, max players, whitelist and more, and Files lets you browse the server folder or import your own jars.

Friends without a Minecraft account (cracked)

Under Player accounts, switch on Allow cracked players and restart. This turns off Minecraft’s account check, so people without a paid account can join. The catch: anyone can then join under any name, even yours. Turn on the whitelist in Settings, or tap Add login protection to install AuthMe, so players have to /register and /login. Switching the mode changes every player’s ID, so inventories, ops and whitelist entries from before won’t match.

Made for phones

VoxelPort checks your phone’s memory and cores and picks a Performance level (Settings): Low-end for 4 GB phones, Balanced for most, High-end for 10 GB+. It sets view distance, mob limits, the garbage collector and background threads, suggests a safe amount of RAM, and warns you if the phone is hot or the battery is low. The app also stops polling when it’s in the background to save battery.

Don’t burn through your mobile data

When friends play on your server, their game travels through your phone’s connection. On Wi‑Fi that costs nothing; on a mobile plan (say 1 GB a day) it adds up, so the app looks after it for you:

  • Wi‑Fi is recommended. A yellow card tells you when you’re on mobile data, with a shortcut to your Wi‑Fi settings, and Make Public asks first.
  • It counts what it uses. The Data use panel shows today’s mobile and Wi‑Fi use. The numbers are an estimate; Android’s own App data usage screen has the exact figure.
  • A daily limit. Choose Wi‑Fi only, 250 MB, 500 MB (the default), 1 GB, 2 GB or no limit. Near the limit you get a notification; at the limit the app stops sharing (the server keeps running on your phone) until you’re on Wi‑Fi or add more for the day.
  • Data saver. Gives each player a smaller world around them and fewer far-away updates, so each one uses much less data. Turn it on in Data use, then restart the server.
  • Big downloads ask first. Setting up the server (about 110 MB), app updates (about 50 MB) and large plugins or mods ask before using mobile data. Plugin pictures are hidden on mobile data too.

As a rough guide, each player online uses about 10–50 MB an hour, and much more while exploring new land. If you only have a small daily allowance, host on Wi‑Fi, use Data saver, and keep the player count low.

Keep it running smoothly

  • Keep the phone charged. Hosting is steady CPU work; plug it in for long sessions.
  • Wi‑Fi beats mobile data. Every player’s traffic flows through your connection. On mobile data, keep an eye on the Data use panel.
  • Don’t force-close the app. The server runs in a foreground service with a notification; leave it there while you play.
  • Use the console. Make yourself admin with op YourName, or whitelist friends with whitelist on then whitelist add Name.

Questions

Can my Android phone really run a Minecraft server?

Yes. VoxelPort for Android runs a full Paper (Java Edition) server on the phone, with a real Java 25 runtime bundled in. A phone with 6–8 GB of RAM comfortably hosts a few friends.

Do my friends need Android or the app?

No. You (the host) run the app; friends join with normal Minecraft on any device — PC, phone or console. Turn on Bedrock players and phone/console players can join too.

Why is it an APK and not on the Play Store?

The app is distributed as a direct APK for now. A Play Store listing is planned. Sideloading is safe here — it’s the same open project as the desktop app.

Will it drain my battery or data?

Hosting uses CPU and keeps the screen-off server awake, so keep the phone on a charger for long sessions. Every player’s traffic goes through your connection, so Wi‑Fi is best. On mobile data the app counts what it uses, warns you before big downloads, stops sharing at a daily limit you choose (500 MB by default), and has a Data saver mode that sends each player less.

How much mobile data does hosting use?

Roughly 10–50 MB per hour for each player online while they build or mine, and a lot more while they explore new land or fly, because new world has to be sent to them. Setting up the server downloads about 110 MB once. On a 1 GB-per-day plan that is a few players for a few hours, so host on Wi‑Fi when you can. The app shows what it used today and stops sharing at your limit.

Can friends without a paid Minecraft account join?

Yes, if you turn on "Allow cracked players" in the app (it sets online-mode to false). The trade-off is security: with the account check off, anyone can join under any name, including an admin’s, so use the whitelist or the one-tap login plugin (AuthMe) the app offers. Switching also changes players’ IDs, so existing inventories and ops won’t carry over.

Will it run well on my phone?

The app checks your phone and picks a performance level (Low-end, Balanced or High-end) that sets the view distance, mob limits, memory use and background threads to suit it. A phone with 4 GB of RAM can host a few friends on Low-end; 8 GB or more runs comfortably. You can change the level in Settings.

Does it work on Jio/Airtel or mobile data?

Yes, there’s no port forwarding and CGNAT (Jio, Airtel, mobile data) is not a problem. But mobile data is the weakest way to host: the connection can drop for a moment, and players get disconnected when it does. Wi‑Fi is much steadier.
