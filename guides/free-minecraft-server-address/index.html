Free Minecraft Server Address (Custom for Supporters)

How to get a free Minecraft server address, and a custom one with no port number like yourname.voxelport.in. What you get free and what supporters get.

An address like play.voxelport.in:26137 works, but it’s hard to remember and easy to mistype. A custom address such as yourname.voxelport.in (a supporter perk) is easier to share, and Java players don’t need to type a port.

Claim a custom address (supporters)

Your free address always works. New custom names are a supporter perk: see how to become a supporter.

Download the Windows installer (the new app, 2.0 beta; Windows 10 and 11; if Windows warns, click More info → Run anyway; if Windows 11 Smart App Control blocks it, see the download page). It's free and open source; to host, join our Discord server once.

  1. Start your server and click Make public.
  2. Under Get a custom address, type a name: 3–20 letters, numbers or dashes.
  3. Click Claim. After a short wait the address shows as Your address.
  4. Share yourname.voxelport.in. Java players paste it into Multiplayer → Add Server as it is.

Each install can hold one name. Use Change to switch names or Remove to release it. If a name isn’t used for 60 days, it’s released automatically.

New names can take a minute or two to work everywhere, because DNS changes need time to spread. If a friend gets “Unknown host”, wait a bit and try again.

How Minecraft skips the port: SRV records

Normally a domain name only points to an IP address, so you still need the port. Minecraft Java also checks for a special DNS record called an SRV record, named _minecraft._tcp.yourname.voxelport.in, which says “the server for this name is at play.voxelport.in, port 26137”. Minecraft reads that and connects to the right port by itself.

When you claim a name, VoxelPort creates that SRV record for you and reserves your port, so the address keeps working every time you go public.

Bedrock players still need the port

Bedrock Edition doesn’t read SRV records. Bedrock players enter your name as the server address and the port shown in VoxelPort on the Bedrock line. See the crossplay guide.

Using your own domain

If you own a domain, you can point a name like mc.example.com at your VoxelPort server:

  1. Open VoxelPort and note your public port (like 26137). It stays the same for your install, so the record keeps working.
  2. At your DNS provider, add an SRV record: service _minecraft, protocol _tcp, name mc, priority 0, weight 5, port your VoxelPort port, target play.voxelport.in.
  3. Java players can then join with mc.example.com.

Questions

Is the custom address free?

The regular address (like play.voxelport.in:26137) is free for everyone. A custom name like yourname.voxelport.in is a supporter perk. A name that isn’t used for 60 days is released so others can claim it, unless its owner is a supporter.

Why does my address work without a port?

VoxelPort creates a DNS SRV record for your name. Minecraft Java looks up that record and finds the port automatically.

Can I use my own domain?

Yes. Add an SRV record on your domain pointing to play.voxelport.in and your VoxelPort port. Your port stays the same for your install, so the record keeps working.
