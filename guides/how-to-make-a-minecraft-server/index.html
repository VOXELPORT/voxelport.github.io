How to Make a Minecraft Server for Free (Java + Bedrock)

Make a free Minecraft server with friends in minutes: install VoxelPort, press Start, share the address. No port forwarding. Java and Bedrock players can join.

Making your own Minecraft server takes about two minutes and costs nothing. This guide covers the choices that matter (server type, RAM, Java) and the part that usually goes wrong: letting friends outside your home join.

What you need

  • A Windows 10/11 PC with at least 8 GB of RAM (16 GB is comfortable).
  • A normal home internet connection. Jio, Airtel and mobile data are fine.
  • Minecraft: Java Edition for you and your friends (Bedrock players can join too, see below).

Choose a server type

TypeBest for
PaperSurvival with friends, plugins (EssentialsX, LuckPerms…). Faster than vanilla. The usual choice.
FabricMods and modpacks (and performance mods like Lithium).
VanillaExactly the official game, no add-ons.

How much RAM to give it

ServerRAM
Paper or vanilla, 2–5 friends2–3 GB
Paper, 5–15 players or a large world4–6 GB
Modpack (Fabric)6–8 GB

More isn’t always better: leave at least 4 GB for Windows and the game you play on the same PC.

Make the server

Download the Windows installer (the new app, 2.0 beta; Windows 10 and 11; if Windows warns, click More info → Run anyway; if Windows 11 Smart App Control blocks it, see the download page). It's free and open source; to host, join our Discord server once.

  1. Open VoxelPort and click + Add Server.
  2. Pick a template (Survival SMP, Creative, Modded…) or choose the type and Minecraft version yourself.
  3. Set the RAM, agree to Minecraft’s EULA, and click Install & start. VoxelPort downloads the server and the right Java version for you.
  4. When it says Online, you can join it yourself at localhost.

Let friends join from anywhere

The classic way is port forwarding, which doesn’t work on most Indian connections and many others (CGNAT). VoxelPort skips it:

  1. Click Make public. You get an address like play.voxelport.in:26137.
  2. Supporters can optionally claim a custom name, like yourname.voxelport.in, so friends don’t need the port.
  3. Friends open Multiplayer → Add Server, paste the address and join.
Want phone and console players too? Open the server’s Settings and turn on Bedrock players. They join with the same address and port as Java players. See the crossplay guide.

Next steps

  • Turn on the whitelist so only your friends can join: whitelist on, then whitelist add Name in the console.
  • Make yourself an operator: op YourName.
  • Something broke? See fixes for common crashes.

Questions

How do I make a Minecraft server for free?

Install VoxelPort, click + Add Server, choose a server type and version, and click Install & start. Then click Make public to get an address your friends can join. It’s free, needs no port forwarding, and you join our Discord once.

How much RAM does a Minecraft server need?

About 2 GB for a small vanilla or Paper server with a few friends, 4 GB for more players or a big world, and 6–8 GB for most modpacks. Leave at least 4 GB for Windows and your own game.

Should I use Vanilla, Paper or Fabric?

Paper for a normal survival server with plugins (it’s faster than vanilla), Fabric for mods and modpacks, and Vanilla if you want it exactly like the official game.

Can my friends join from a different house or city?

Yes. Once the server is public, anyone with the address can join from anywhere, as long as your PC and the server are on.

Can phone (Bedrock) players join a Java server?

Yes, on a Paper or Fabric server: turn on Bedrock players in VoxelPort’s server settings. It installs Geyser and Floodgate so Bedrock players join the same world.
