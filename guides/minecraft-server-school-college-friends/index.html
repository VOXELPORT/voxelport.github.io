Minecraft Server for School or College Friends (Free)

Make a free Minecraft server for your school or college friends: no router access, no hostel Wi-Fi settings, no port forwarding. Works from a laptop or phone.

Realms costs money every month, and “Open to LAN” stops working as soon as someone goes home. If you want one Minecraft world for your class, batch or hostel, the cheapest way is to host it yourself and share an address. It takes about five minutes and costs nothing.

Who should host

The world lives on the host’s PC, so it’s only online while that PC is on. Pick the person who:

  • has the best PC or laptop (8 GB of RAM or more is comfortable),
  • has home broadband (Jio Fiber, Airtel and similar are fine, even with CGNAT),
  • and is happy to keep it running in the evenings or at weekends when you all play.
Want two hosts? Take turns: zip the server folder, share it, and the other person uses Import Existing Server. Only run it on one PC at a time, or the world splits into two copies.

Set up the server

Download the Windows installer (the new app, 2.0 beta; Windows 10 and 11; if Windows warns, click More info → Run anyway; if Windows 11 Smart App Control blocks it, see the download page). It's free and open source; to host, join our Discord server once.

  1. Click + Add Server and pick Survival SMP. If some friends play on phones, pick Java + Bedrock instead.
  2. Give it 3–4 GB of RAM, agree to the Minecraft EULA, and click Install & start.
  3. When it says Online, click Make public.
  4. Supporters can claim a name such as ourclass.voxelport.in under Get a custom address; the free address also stays the same between restarts.
  5. Post the address in your class or hostel group chat. Friends add it under Multiplayer → Add Server.

Keep strangers out: the whitelist

Anyone who sees a public address can try to join. If the server is only for your group, turn on the whitelist:

  1. In VoxelPort, open the server’s Settings and turn on white-list.
  2. In the console, add each friend by their Minecraft name: whitelist add Name.
  3. Make yourself an operator with op YourName so you can manage the game from inside Minecraft.

Players who aren’t on the list see “You are not whitelisted on this server” and can’t join.

Ideas for a class server

  • Batch SMP: plain survival where everyone builds a town together. The Survival SMP template is made for this.
  • Build project: recreate your school or campus on a Creative Flat server.
  • Hardcore event: one life each, over a weekend. Use the Hardcore template.
  • Mixed devices: PC and phone players together with the Java + Bedrock template. See the phone players guide.

Questions

Can I host a Minecraft server on college Wi-Fi?

Often yes, because VoxelPort only makes an outgoing connection, like a website. Some campus networks block games or unusual ports. If it doesn’t work, host from home or use a mobile hotspot, and follow your college’s network rules.

Why can’t my friends in the same hostel see my LAN world?

Many hostel and campus networks use “client isolation”, which stops devices on the Wi-Fi from talking to each other. LAN worlds can’t be seen there. Putting the server online with an address gets around it.

How many friends can join a free server?

It depends on your PC and upload speed, not on VoxelPort. A normal laptop giving the server 4 GB handles about 5–10 players on Paper; a desktop handles more.

Do my friends need to pay or sign up?

No. They need their own copy of Minecraft. Nobody needs a VoxelPort account, and only the host installs VoxelPort.
