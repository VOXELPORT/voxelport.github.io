Minecraft Server ohne Portfreigabe hosten (kostenlos)

Minecraft Server ohne Portfreigabe kostenlos hosten, auch bei DS-Lite und CGNAT. So geht es mit VoxelPort: Java und Bedrock, ohne Router-Einstellungen.

Du willst mit Freunden Minecraft spielen, aber die Portfreigabe im Router klappt nicht? Bei vielen Anschlüssen liegt das an DS-Lite oder CGNAT: Dein Anbieter gibt dir keine eigene öffentliche IPv4-Adresse, und eingehende Verbindungen erreichen deinen Router nie. Mit einem Relay kannst du trotzdem einen Server hosten, ohne irgendetwas freizugeben.

So funktioniert ein Relay

Router blockieren eingehende Verbindungen, erlauben aber ausgehende. Dein PC verbindet sich deshalb von sich aus mit dem Relay und hält die Verbindung offen. Das Relay gibt dir eine öffentliche Adresse. Wenn ein Freund sich damit verbindet, leitet das Relay den Verkehr durch die bestehende Verbindung zu deinem PC. Deine Heim-IP bleibt dabei für deine Mitspieler unsichtbar.

VoxelPort hat ein Relay in Europa, damit der Ping für Spieler in Deutschland und den Nachbarländern niedrig bleibt.

In fünf Schritten einrichten

Download the Windows installer (the new app, 2.0 beta; Windows 10 and 11; if Windows warns, click More info → Run anyway; if Windows 11 Smart App Control blocks it, see the download page). It's free and open source; to host, join our Discord server once.

  1. Klicke auf + Add Server, wähle Vanilla, Paper oder Fabric und eine Version und klicke auf Install & start. Java wird bei Bedarf automatisch installiert.
  2. Sobald der Server Online anzeigt, klicke auf Make public. Die Einstellung Region steht auf Auto, dann wählt die App das schnellere Relay selbst.
  3. Kopiere die angezeigte Adresse.
  4. Deine Freunde öffnen Minecraft, gehen auf Mehrspieler → Server hinzufügen, fügen die Adresse ein und treten bei.
  5. Für Bedrock-Spieler auf Handy oder Konsole schaltest du in den Servereinstellungen Let Bedrock players join ein.

Gut zu wissen

  • Dein PC muss laufen, solange gespielt wird. VoxelPort ist kein 24/7-Hosting.
  • Das Relay in Europa ist neu und wird von einem Studenten betrieben, daher gibt es keine Verfügbarkeitsgarantie. Fällt es aus, stelle die Region auf Indien, dann läuft dein Server weiter.
  • Datenschutz: Das Relay schreibt keine IP-Adressen in seine Logs. Einzelheiten stehen in der Datenschutzerklärung (auf Englisch).
  • Mehr zu DS-Lite und CGNAT: Guide auf Englisch.

Questions

Muss ich im Router einen Port freigeben?

Nein. Dein PC baut selbst eine ausgehende Verbindung zum Relay auf. Am Router musst du nichts einstellen.

Funktioniert das bei DS-Lite oder CGNAT?

Ja. Bei DS-Lite und CGNAT kommen eingehende IPv4-Verbindungen nicht bis zu deinem Router, aber ein Relay braucht keine eingehende Verbindung.

Was kostet VoxelPort?

Nichts. Die App, das Relay und die Adresse sind kostenlos, ohne Konto und ohne Warteschlange.

Müssen meine Freunde etwas installieren?

Nein. Sie öffnen Minecraft, gehen auf Mehrspieler, Server hinzufügen, fügen deine Adresse ein und treten bei.
