Minecraft Server Kaise Banaye: Free, Bina Port Forwarding

Minecraft server kaise banaye, free mein aur bina port forwarding ke. Jio aur Airtel par bhi chalta hai. VoxelPort se step-by-step Hinglish guide.

Dosto ke saath apna Minecraft server chahiye, par Aternos pe queue lagti hai aur port forwarding Jio pe chalta hi nahi? Koi baat nahi. Is guide mein seekho apne PC pe free server kaise banaye aur dosto ko kahin se bhi join kaise karaye, bina router settings chhede.

Kya chahiye

  • Windows 10/11 PC, kam se kam 8 GB RAM.
  • Normal internet: Jio Fiber, AirFiber, Airtel, ya mobile hotspot bhi chalega.
  • Minecraft Java Edition (phone wale dost Bedrock se bhi aa sakte hain).

Port forwarding kyu fail hota hai

India mein zyada tar ISP CGNAT use karte hain: ek public IP bahut saare ghar share karte hain. Tumhare router ko asli public IP milta hi nahi, isliye 25565 port forward karne ke baad bhi dost connect nahi kar paate. VoxelPort ulta kaam karta hai: tumhara PC khud relay se connect hota hai, aur dost relay ke address pe join karte hain. Router mein kuch change nahi karna.

Server banao (2 minute)

Download the Windows installer (the new app, 2.0 beta; Windows 10 and 11; if Windows warns, click More info → Run anyway; if Windows 11 Smart App Control blocks it, see the download page). It's free and open source; to host, join our Discord server once.

  1. VoxelPort kholo aur + Add Server dabao.
  2. Template chuno (Survival SMP, Creative, Modded…) ya khud type chuno: Paper (plugins, sabse common), Fabric (mods) ya Vanilla.
  3. RAM set karo (2–3 GB dosto ke liye kaafi hai), EULA accept karo, aur Install & start dabao. Sahi Java bhi app khud download kar leta hai.
  4. Online dikhe toh Make public dabao. Address milega, jaise play.voxelport.in:26137.
  5. Supporters apna custom naam claim kar sakte hain, jaise tumharanaam.voxelport.in, taaki port yaad na rakhna pade.
  6. Dosto ko bhejo. Woh Multiplayer → Add Server mein address daal ke join karenge.
Phone wale dost bhi chahiye? Server ki Settings mein Bedrock players on karo. Wahi address use karke Bedrock se join kar sakte hain.

Server safe rakho

  • Sirf apne dosto ko allow karo: console mein whitelist on, phir whitelist add DostKaNaam.
  • Khud ko admin banao: op TumharaNaam.

Tips

  • Lag ho raha hai? RAM thodi badhao, ya Paper use karo. App mein CPU, RAM aur TPS live dikhta hai.
  • Server crash hua? App simple bhasha mein batata hai kya hua aur kaise theek karein. Crash fixes guide bhi dekho.
  • Hostel Wi-Fi pe dost join nahi kar pa rahe? Mobile data se try karo. College friends guide dekho.

Questions

Minecraft server free mein kaise banaye?

VoxelPort app install karo, + Add Server dabao, server type aur version chuno, aur Install & start karo. Phir Make public dabao, tumhe ek address milega jo dosto ko bhej sakte ho. Sab free hai, account nahi chahiye.

Jio Fiber pe port forwarding kyu nahi chalta?

Jio aur Airtel ke zyada tar connection CGNAT pe hote hain, matlab tumhare router ko public IP nahi milta. Isliye port forward karne se bhi bahar se koi connect nahi kar pata. VoxelPort relay se connect karta hai, toh port forwarding ki zarurat hi nahi.

Kitni RAM chahiye?

2–5 dosto ke liye 2–3 GB kaafi hai. Zyada players ya bada world ho toh 4–6 GB, aur modpack ke liye 6–8 GB. PC mein kam se kam 4 GB Windows ke liye chhod do.

Kya phone wale dost (Bedrock) bhi join kar sakte hain?

Haan. Paper ya Fabric server ki Settings mein Bedrock players on karo. Java aur Bedrock dono ek hi world mein khel sakte hain.

Kya PC band hone pe server chalega?

Nahi. Server tumhare PC pe chalta hai, toh jab tak dost khel rahe hain, PC on rehna chahiye.
